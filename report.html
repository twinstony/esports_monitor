4. 根因分析

4.1 为什么比赛结束后仍持续开单？

监控主循环 (monitor.py): for match in live_matches: → _check_single_match(match) → detector.detect(match) # 形态检测 → 加载价格序列 → 信号检测 → 模拟下单 → 未检查比赛是否实际结束 → 依赖 end_time 判断，但 end_time 是市场结算时间（42h+）
  • 🔴 根因1：Polymarket 的 end_time 是市场结算时间（通常 42-46 小时），而非比赛实际结束时间
  • 🔴 根因2：监控循环仅检查 match.status == "ended"，但 status 未被正确更新为 "ended"
  • 🔴 根因3：VWAP 计算在低流动性市场返回极端价格（如 0.001），simulator 未二次检查
  • 🔴 根因4：冷却期仅 15 分钟，42 小时可产生约 168 次检测循环，即使每次只有少数信号触发，累计开单量仍然很大

4.2 价格达到 0.99 后是否反复开单？

场景交易数说明
价格达到极端值后开单2价格触发终止机制基本有效（仅 2 笔漏网）
价格未达极端值但比赛已结束~6,714比赛结束后价格在 0.3-0.7 徘徊，持续产生信号

用户的假设"价格始终 ≥0.99 然后频繁开单"不成立。真实情况是比赛结束后价格可能在 0.3-0.7 区间波动（因为 Polymarket 市场尚未结算），形态策略持续检测到信号并开单。
